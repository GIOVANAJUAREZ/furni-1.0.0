Descarga e instalación

  1. Haz clic en Descargar archivo para obtener el paquete (.zip).
  2. Descomprime el archivo en una carpeta de tu preferencia.
  3. Abre el proyecto:
    • HTML estático: abre index.html en tu navegador.
    • Proyecto Node: ejecuta estos comandos:
# En la carpeta del proyecto
npm install
npm run dev  # o npm start, según el proyecto
